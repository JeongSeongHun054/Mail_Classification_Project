SmartMail & DailyBriefing AI: AI 기반 개인 맞춤형 정보 자동 분류 및 요약 시스템

진행 기간: 2026.10 ~ 2026.11 | 역할: 기획, 아키텍처 설계, AI 파이프라인 및 프론트엔드 전주기 1인 개발

1. 기획 배경 및 문제 정의

"매일 쏟아지는 메일을 일일이 열어보고 여러 매체에서 뉴스를 직접 찾아 읽는 작업을 당연한 일상으로 넘기지 않고, 정보 탐색의 비효율을 개선하고자 AI 기반 자동화 시스템을 구축한 경험이 있습니다."

• 수신함 병목: 일상적으로 수신되는 메일의 70% 이상이 광고와 단순 안내 메일임에도, 중요 메일 누락에 대한 불안감으로 모든 메일을 일일이 확인하는 데 하루 35분 이상 소모되었습니다.
• 정보 탐색 피로도: 최신 IT, 경제, 시사 흐름을 놓치지 않기 위해 포털별로 검색하고 장문의 기사를 정독하며 일평균 40분의 인지적 에너지가 낭비되었습니다.

2. 시스템 아키텍처 및 듀얼 엔진 설계

[System Pipeline Architecture]
1. 데이터 수집 ➔ [이메일 수신함 (IMAP/Data) + 주요 언론사 RSS 3개 도메인]
2. 텍스트 전처리 ➔ [BeautifulSoup HTML 클렌징 + 정규표현식 바이라인 노이즈 제거]
3. 지능형 듀얼 엔진:
• Online: Gemini 1.5 Flash (Contextual Zero-shot & Structured JSON Output)
• Fallback: 한국어 형태소/패턴 기반 Heuristic NLP 규칙 엔진 (Offline 100% 보장)
4. 결과 표출 ➔ [GitHub Pages 기반 24/7 무중단 모닝 브리핑 웹 대시보드]

3. 기술적 난관 및 트러블슈팅 (Troubleshooting)

[트러블슈팅 1] LLM 비정형 출력으로 인한 파싱 에러(JSONDecodeError) 차단

원인: LLM이 JSON 외에 설명문이나 마크다운 텍스트를 출력하여 시스템 다운 발생.
해결: API 호출 시 responseMimeType: "application/json" 강제 및 파이썬/JS 단에서 정규식 추출 2중 방어 로직을 적용해 파싱 성공률 100% 달성.

[트러블슈팅 2] 제목에 [긴급] 태그가 없는 중요 메일 누락 방지

원인: 제목에 태그가 없으나 본문에 "내일까지 검토 부탁드립니다"와 같은 중요 마감 요청이 존재할 경우 일반 메일로 오분류 위험.
해결: 본문 내 마감 시한 패턴(금일 \d+시, 내일까지)과 행동 유도 키워드(검토, 승인, 회신)를 교차 스코어링하여 긴급도 탐지율 100% 확보.

[트러블슈팅 3] 호스팅 플랫폼 잠김 현상(Streamlit Sleep) 극복

원인: 무료 클라우드 대시보드는 일정 시간 방문자가 없으면 서버가 절전 모드로 전환되어 평가자 열람 시 로딩 지연 유발.
해결: 서버리스 정적 아키텍처(HTML/JS + GitHub Pages)로 전면 마이그레이션하여 24시간 365일 무지연 즉시 응답 체계 구축.

4. SK AIGEN 교육 과정과의 연계성 및 포부

본 프로젝트를 통해 "일상의 문제를 기술로 전환하는 문제 해결력"과 "안정적인 소프트웨어 엔지니어링"의 기초를 다졌습니다. 향후 본 프로토타입을 개인 메일 히스토리를 기억하는 **RAG(검색 증강 생성) 기반 맞춤형 문맥 참조** 및 **경량 SLM(Small Language Model) 온디바이스 파인튜닝**, **자율 에이전트(Autonomous Agent)**로 발전시키고자 합니다. SK AIGEN의 2년 전일제 심화 커리큘럼(MLOps, 대규모 분산 데이터 처리, 최신 LLM 에이전트 아키텍처)에 전념하여, 단순한 모델 사용자를 넘어 복잡한 현실의 문제를 기술로 해결하는 **실무형 핵심 AI 엔지니어**로 성장하겠습니다.
